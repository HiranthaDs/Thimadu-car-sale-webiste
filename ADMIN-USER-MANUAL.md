# Thimadu website admin: quick guide

## Sign in

1. Open **`/admin.html`** on the website (for example, `https://your-domain/admin.html`).
2. Enter the admin password provided by the site owner and select **Open dashboard**. Keep the password private.

## Manage content

- **Vehicles:** Select **Vehicles → Add / edit**. Enter the brand, model, year and at least one photo; add the price, details and availability as needed. You can add up to 20 photos and drag them to set their order. Select **Save vehicle** and wait for the upload to finish. To change an existing listing, use **Vehicles → Manage → Edit**, then **Save changes**.
- **Happy Customers:** Select **Happy Customers**. Add a headline and customer image, then choose **Active** to show the story or **Hidden** to keep it off the website. Use **Display order** to arrange stories, then select **Save customer story**. Up to 36 active stories appear in the homepage image sphere.
- **Videos:** Select **Videos**. Add a headline, then upload an MP4, WebM or MOV file (up to 100 MB), or paste a YouTube, Facebook, TikTok, Instagram or Vimeo link. Set **Visibility** and **Display order**, then select **Save video**. Keep the page open while a file uploads. The **How to add videos** button has more help.

Use **Edit** on a content card to update it. The red bin button deletes its database record after confirmation. Use **Refresh** to reload the admin lists, then check the public website to confirm your changes.

## Sign out

Select the **Log out** icon in the top right when finished, especially on a shared device.
